What reviewers will see on the site

Agent runs the local model; Compare shows model-only, agent-only, and combined results; System explains the architecture. A ?details=1 URL exposes the Prompt, Tools, and Data reference tabs when needed.

The Run Inspector shows the system, user, assistant, and tool messages; cumulative token usage; and a scoped date-check receipt for every tool. These receipts make the checked cutoff fields visible; the structural snapshots and regression tests provide the stronger leakage guarantee. The inspector exposes model context, not hidden chain-of-thought.

What was fixed after the model integration

Pregame features are reconstructed only from information available by the selected date. The agent can run against a structural snapshot with later outcomes removed; the model-only path independently enforces the same cutoff against its exports.

Stat-line output is also suppressed when the gated injury report already lists that player out. The agent tool returns an explicit unavailable result; model-only omits the player instead of implying participation.

Why winning 66.5% can still lose money

Accuracy ignores price. If the market's fair probability is p and the measured sportsbook margin is h = 3.75%, the evaluation approximates offered decimal odds as 1 / [p(1+h)]. If our true win estimate is q, expected return per dollar is q / [p(1+h)] - 1.

That means a 60% market favourite needs our estimate to exceed 62.25% just to clear the modeled margin. Picking the right winner is not enough; the probability edge must also beat the price. The reconstructed prices were checked against 19,807 quoted games: correlation 0.9959, 2.93 percentage-point mean absolute error, and a measured 3.75% average margin.

How Polymarket changes the comparison

Polymarket is a peer-to-peer central-limit-order-book market. A YES share bought at the executable ask a pays $1 if it wins, so the basic edge is q - a, not an assumed sportsbook hold. The real hurdle is the ask plus spread, slippage, and any taker fee.

For sports, Polymarket documents a taker fee of 0.03 × p × (1-p) per share. At a 60-cent price that is 0.72 cents, so a taker needs roughly 60.72% belief to break even before spread and slippage. Maker orders have no trading fee but may not fill. Availability and liquidity vary, and sports orders are cancelled automatically once the game begins.

Sources: market model, prices and order book, fees, and sports-market behavior.

Evidence and limits

The predictor was trained on 2023-24 and 2024-25 and tested on all 1,322 games of 2025-26. Train accuracy was 66.8% and test accuracy was 66.5%, a 0.3-point gap. On probability quality, it trails the closing market: log loss 0.6118 versus 0.5782 and Brier score 0.2116 versus 0.1977.

A live local run produced seven passed gate receipts, zero post-cutoff records, 17 inspectable messages, and 57,106 cumulative tokens processed. The 80-game agent comparison is encouraging but small: the combined agent improved from 58.8% before skills to 66.2% after skills. Treat that as evidence the constraints help, not as a betting-performance claim.
